# tapwars.world

[Visit tapwars.world](https://tapwars.world).

Tapwars.world is a real-time global tapping battle where visitors compete for their country and city. Location is detected approximately through trusted proxy data, GeoIP, or optional browser-assisted lookup, and may be unavailable or inaccurate. Tap verification uses Cloudflare Turnstile and short-lived server nonces, while country totals are stored in PostgreSQL when configured. Run it locally with `bun install` followed by `bun run dev`.
